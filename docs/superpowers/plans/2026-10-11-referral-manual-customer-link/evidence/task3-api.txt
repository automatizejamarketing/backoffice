### Nota — o motivo gravado no #14 contém U+FFFD
No Git Bash do Windows, o curl nativo recebe os argumentos convertidos para a code page ANSI (CP1252):
'ção —' via --data chega como bytes e7 e3 6f 20 97 (UTF-8 inválido) e o request.json() troca cada byte por U+FFFD.
Com --data-binary @arquivo-utf8 os mesmos caracteres chegam como c3a7 c3a3 6f20 e28094 e são decodificados certos.
Hex do motivo no banco: 5665726966696361efbfbdefbfbd6f20646f2076efbfbd6e63756c6f206d616e75616c20287370656320323032362d31302d31312920efbfbd205461736b2033 (56 caracteres).
